# SmartCash — Proyecto 1 (Fase 0 (base del proyecto))

Base compilable: tema, estilos, base de datos, repositorio con métodos vacíos, Splash, menú inferior y pantallas vacías.

Abrir la carpeta con Android Studio (File > Open) y ejecutar con el emulador.
Si la app falla al abrir después de cambiar la base de datos: desinstalarla del emulador.

No incluye `build/`, `.gradle/`, `.idea/` ni `local.properties` (Android Studio los genera).
